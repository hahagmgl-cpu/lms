# 🦷 Smile Design Pro v2.0

**exocad 및 치과 디지털 설계 소프트웨어를 위한 반투명 오버레이 프로그램**

---

## ✨ 주요 기능

### 13가지 치아 설계 가이드
1. **정중선 (Midline)** — 얼굴/치아 중심축
2. **스마일 아크** — 하순 곡선 기준
3. **절단연 (Incisal)** — 절단연 높이선
4. **황금비율** — 1.618 : 1 : 0.618 분할
5. **폭/길이 비율 박스** — 치관 W/L% 시각화
6. **대칭 가이드** — 치아별 경계 미러라인
7. **치은 정점 (Zenith)** — 개별 조절 가능
8. **치은 라인 곡선** — 제니스 점들을 잇는 곡선
9. **치축 경사 (Axial)** — 기울기 조절
10. **접촉점 (Contact)** — 인접면 높이
11. **절단 엠브레저** — V자 함몰 (원심 방향 강화)
12. **협측 회랑 (Corridor)** — 버컬 영역
13. **치아 사이즈 정보** — mm 단위 정보

## 🎮 기본 사용법

### 프레임 이동 (Alt 모드)
1. **Alt 키 누르기** → 프레임 주변 커서 변경 (SizeAll)
2. **드래그** → 프레임 이동
3. **Alt 놓기** → 클릭 통과 모드로 복귀

### 편집 모드
1. **Ctrl+Alt+E** 또는 패널의 "편집 모드 켜기"
2. 프레임 경계 드래그 → 크기 조절
3. 프레임 중심 드래그 → 위치 이동
4. ESC 또는 우클릭 → 종료

### 캘리브레이션
1. **🎯 캐닌 2점 캘리브레이션** (또는 Ctrl+Alt+C)
2. 좌측 견치 끝 클릭 → 우측 견치 끝 클릭
3. 프레임 자동 조정

### 가이드 ON/OFF
- 컨트롤 패널 "📋 가이드" 탭에서 체크박스
- 또는 Ctrl+Alt+1~T 단축키

### 스타일 조절 (색상/굵기/투명도)
- 패널 **🎨 스타일** 탭
- 전역 또는 개별 가이드별 조절

### 프리셋 저장
- 패널 **💾 프리셋** 탭
- 자동 저장 (마지막 세션): `~/.smile_overlay/last_session.json`

## ⌨️ 단축키 (커스터마이징 가능)

| 단축키 | 기능 |
|:---:|:---|
| `Ctrl+Alt+H` | 오버레이 전체 ON/OFF |
| `Ctrl+Alt+E` | 편집 모드 토글 |
| `Ctrl+Alt+C` | 캐닌 캘리브레이션 |
| `Ctrl+Alt+1~4` | 정중선, 스마일 아크, 절단연, 황금비율 |
| `Ctrl+Alt+5~T` | 기타 가이드들 |
| `Alt + 드래그` | 프레임 이동 |
| `ESC` / `우클릭` | 모드 종료 |

모든 단축키는 패널 **⌨️ 탭**에서 재설정 가능합니다.

## 🔧 고급 설정

### 프리셋 폴더
- Windows: `C:\Users\[Username]\.smile_overlay\presets\`
- macOS: `/Users/[Username]/.smile_overlay/presets/`
- Linux: `/home/[Username]/.smile_overlay/presets/`

### 치아 크기 커스터마이징
`smile_overlay/config.py` → `OverlayState` 클래스의
```python
self.tooth_widths_mm = [7.5, 6.5, 8.5, 8.5, 6.5, 7.5]
self.tooth_heights_mm = [10.0, 9.0, 11.0, 11.0, 9.0, 10.0]
```

## 💡 팁

- **선이 옅으면**: 🎨 탭 → "전체 불투명도" 증가
- **선이 두꺼우면**: 🎨 탭 → "전체 선 굵기" 감소
- **Alt 키 미동작** (Windows 아님): Windows 환경 권장
- **프레임 위치 유지**: 프로그램 종료 시 자동 저장 (5초 간격)
